# CleanCruisers

Flutter app for CleanCruisers — doorstep car wash & detailing in Delhi NCR.
Customers browse services with clear prices by car size, request a preferred arrival window in
the app, and track confirmation and progress there. Staff manage bookings and worker assignments
in a separate, protected operations desk. Customers pay after the service.

See [SETUP.md](SETUP.md) for setup, project structure and how to update prices and business info.

See [docs/OPERATIONS_MVP_SETUP.md](docs/OPERATIONS_MVP_SETUP.md) to connect Firebase and set up staff access. Until Firebase is configured, online bookings stay disabled rather than showing a false confirmation.

```bash
flutter pub get
flutter run
flutter test
```
